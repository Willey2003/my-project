# Strategy: the daily rules

1. **Fixed slot, every day.** Mon-Fri 4 h, Saturday 5 h, Sunday 3 h (review + timed practice). 28 h/week.
2. **Same session shape:** recall 15 m -> learn 1 h (guide + docs) -> hands-on lab 2 h -> notes + git commit 30 m -> self-check 15 m.
3. **No new topic until the lab is done and committed.** Every study day ends with a commit.
4. **Sunday = measure.** Timed practice on the week, fix weak spots, plan next week.
5. **Missed a day?** Don't skip content. The schedule slides one day; catch up only if you feel fresh.
6. **Exams:** book about 2 weeks before target, only after a full timed mock finishes with time to spare. See [[Exams]].
7. **Deload:** one lighter 2-hour day per fortnight is allowed (keep the recall block).
8. **Check-in:** each morning a note lands in `Daily/`. Reply `done`, `partial 2.5h` or `missed` in the project thread.
