# Sync this vault on every computer

On each computer:
1. Install **Obsidian** (obsidian.md) and **Git** (git-scm.com).
2. Clone: `git clone -b obsidian-vault https://github.com/Willey2003/my-project devops-vault`
3. Obsidian -> *Open folder as vault* -> pick `devops-vault`.
4. Settings -> Community plugins -> Browse -> install and enable **Git** (Obsidian Git).
5. Git plugin settings: *Auto pull interval* 10, *Auto commit-and-sync interval* 10, *Pull on startup* on.

A new `Daily/` note is committed every morning; your edits are pushed back automatically, so every computer stays the same.
Phone: use Obsidian Sync (paid) or a Git client app such as Working Copy (iOS) / GitSync (Android).
